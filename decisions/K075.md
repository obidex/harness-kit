## K075 · 2026-11-27 · STANDING — a bug sweep by the Agent SDK, paid from the API credit (a trial)

**Asked.** An owner-approved credit plan (filed on the owner's board, option A, one time only) has a part
"one trial: a bug sweep paid from the credit instead of the weekly limit", capped at $30 and ending with
the reviewer's window (22 Dec 2026, 23:59 Damascus). The credit covers the API and the Agent SDK, not
Claude Code sessions. The trial answers two questions: does the credit pay for it, and how do its findings
and cost compare with one module swept the current way (a session, plan usage).

**Decision.**
1. **The SDK, read-only, one module.** `.harness/tools/agent-sweep.mjs` runs the Claude Agent SDK, pinned
   with its lock in `.harness/tools/agent-sdk/` (the package and its Linux x64 binary only, installed with
   `npm ci --ignore-scripts`). Tools: Read, Grep, Glob. A PreToolUse hook in the job refuses every other
   tool and every path outside the checkout (symbolic links resolved, `.git` too, search patterns that
   leave the folder); the repository's settings, hooks, skills and CLAUDE.md are not loaded. Opus at high
   effort; a finding counts as reproduced only with an exact reproduction, otherwise suspected. Running
   tests is a later step, with its own review.
2. **No stored key, and no apiKeyHelper.** The asked design was an `apiKeyHelper` script returning a fresh
   access token. Claude Code sends a helper's value as both `x-api-key` and a Bearer token, and the API
   reads `x-api-key` first (checked 27 Nov 2026 with stand-in values: both headers answer "invalid
   x-api-key", the Bearer alone "Invalid bearer token"), so an access token from the federation would be
   refused. Instead Claude Code's own federation: the job writes GitHub's identity token for the run to a
   0600 file outside the checkout, rewritten every 4 minutes and removed at the end; Claude Code swaps it
   for an access token (Bearer only) and swaps again when one expires (shown against a stand-in API: a
   401 brings a new exchange that reads the file again). Before anything is asked, `claude auth status`
   must name that federation, so no other credential on the machine pays. The agent's process gets an
   environment built by the tool, without GitHub's tokens; its step holds no GitHub token.
3. **Its own federation rule**, tied to `agent-sweep.yml` on the default branch, `workflow_dispatch` and
   the repository's id, made in the Console by the owner's signed-in browser as the earlier rules were.
   The identifiers live in `.github/agent-sweep.json` with `until` and `command` (off by itself, as K055).
4. **Money.** $30 in code for every run the repository ever makes, $15 a run (`usd` may only lower them).
   A run's budget plus $3 is written in the record before it starts and counts until its cost replaces
   it; a run stopped before its first question records $0. The workspace's spend limit is the stop above.
5. **Not installed.** A trial does not belong in every project: `templates/agent-sweep.yml` lies outside
   `templates/workflows/`, and one project copies it by a reviewed change.

**Record.** `.harness/tools/agent-sweep.mjs`, `.harness/tools/agent-sdk/`, `.harness/templates/agent-sweep.yml`;
`review.md` "The agent sweep trial"; `tools/test-agent-sweep.mjs`, in CI.

**Status:** STANDING.
