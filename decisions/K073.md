## K073 · 2026-11-26 · STANDING — the audit's "never edited" test honours the baseline's known commits too; supersedes K067 item 2 for that test

**Asked.** A project's coordinator, 26 Nov 2026. A project's pull request changed one line of a written
decision file. The line quoted the owner and carried a name that the project's rulebook keeps out of every
file (a network name), so the name was replaced by a placeholder. Since then `audit.mjs` C17 FAILs on every
pull request of that project, because the "never edited" test reads the default branch's last 200 commits.
History is never rewritten. Putting the name back breaks the project's rule. Accepting all of C17 in the
baseline would hide the caps, the load budget, the register and any later edit. K067 item 2 had kept this
test out of the `commits` exception.

**Decision.**
1. **Known commits for this test too.** C17's "never edited" test skips exactly the commits the baseline
   lists for C17 (`{ "id": "C17", "commits": [...], "why": ... }`), reading the same list K067 reads, and
   says how many it skipped. Any other commit that changes, deletes or renames a written decision file,
   and any such change on the pull request itself, still FAILs.
2. **For one kind of change only.** `decisions.md`: a written decision is never edited; the exception is a
   change that only takes out what a rule keeps out of files (a name, a host). The baseline's `why` says
   which rule. A correction of meaning is still a new decision that supersedes the old one.
3. **K067 item 2 otherwise stands.** The caps, the load budget, the decisions register and the generated
   references are never skipped, and a `commits` entry is never a whole accepted rule in `--strict`.

**Record.** `.harness/tools/audit.mjs` (C17); `.harness/audit/README.md` "The baseline";
`.harness/decisions.md` "Switching a project". The checks are in `tools/test-decisions.mjs`: a listed edit is
skipped and said; one listed for another rule is not; a later edit, or one on a branch, still fails. The new
case fails without this change.

**Status:** STANDING.
