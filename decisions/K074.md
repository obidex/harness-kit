## K074 · 2026-11-27 · STANDING — a staff guide written from the code, on the full check's job

**Asked.** An owner-approved credit plan (filed on the owner's board, option A, one time only) has a part
"a staff guide for the ERP, in Arabic, one page per screen, written from the code by the Batch API,
checked by a second pass", capped at $15 and ending with the reviewer's window. Nothing in the kit
wrote anything but findings.

**Decision.**
1. **A lens, not a new job.** `harness-sweep.yml`'s `lens` input gains `staff-guide-<language>` (`ar`,
   `en`; a fixed list by name). `sweep.mjs` hands it to `.harness/tools/guide.mjs`. So it rides the full
   check's switch (`until`, K060) and its own federation rule (`sweep_rule`): no new rule, no stored key,
   no settings page, no owner step.
2. **What a page covers.** A screen is a `page` file under an `app/` folder (Next.js style); its section is
   the first route part that is not a group, slot or parameter. A section's request carries its page
   files, the files in their folders and private folders below, and its labels file (named like the
   section in an `i18n`, `locales`, `messages` or similar folder) plus `common`, cut at 100,000
   characters a part; what fits nowhere is listed, never read in part.
3. **Two batches.** The first writes every page (what the screen is for, who can use it, what you see,
   the common tasks, what cannot be undone), only what the code shows. The second gives each page back
   with the same files and asks for every unsupported statement to be corrected, with a list of the
   corrections. Both on the high-risk model, at the Batch API's half price.
4. **Money.** $15 for one guide in code (`sweep_usd` may only lower it). A batch's worst case is written
   in the record before it is sent and counts until its answers are read; a batch that does not fit is
   cut to the sections that do. No batch is sent once the window has ended; one still running then is
   cancelled.
5. **Where it goes.** One record issue, a comment a page, with what the second pass corrected. Nothing is
   committed: the project's coordinator copies the pages where staff read them, after someone has read
   them against the screens.

**Record.** `.harness/tools/guide.mjs`; `harness-sweep.yml` (the lens choice); `review.md` "A staff guide";
`tools/test-guide.mjs`, in CI.

**Status:** STANDING.
