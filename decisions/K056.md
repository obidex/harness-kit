## K056 · 2026-11-21 · STANDING — the session that hands work to another project starts that project's coordinator run itself

**Owner (21 Nov 2026, project chat).** On hearing that wake-ups from outside were failing, he asked
for a way that would "make us not even need this thing", and approved the card with: "whoever
finishes something another project waits on starts that project's coordinator run in the same turn,
from inside, behind the decide script ... This changes only how projects wake each other: no cap, no
'one run at a time' rule and no stop changes, and no timer that polls."

**Context.** K033 starts a run through a job and an outside call to the scheduled task. Where that
call is refused, a wake label waits for the next morning. A session can start a scheduled task of
the same account directly, and the morning start already works that way.

**Decision.**
1. **Same turn.** A session that sends an inbox request, answers or blocks one, closes another
   project's blocker or proves an action it waits on runs `wake.mjs handoff` for that project's
   repository before its turn ends.
2. **Same decision.** The hand-off reads the receiver's claim, receipts and stops and decides as the
   wake job does. It starts a run only on `START`, after it has set the claim and written its
   receipt; otherwise the `wake` label waits on the item. One run at a time, every cap and every
   stop hold; a hand-off sets no stop and lifts none.
3. **Counted.** A hand-off receipt counts as a run in every cap whoever posted it, and its failed
   start as a failed start: the account that posts it could only use a cap up.
4. **The receiver names its task** in `.github/wake.json` (`runTask`). A project without one is
   only queued.
5. **No timer.** Nothing polls for hand-offs. The morning start stays the backstop.

**Leaves alone** the label wake, its job and its caps (K033, K051), for events no session causes.

Homes: `tools/wake.mjs` (`handoff`, `handoffPlan`, `runTaskOf`); `tools/inbox.mjs` (`handoffLine`);
`wake.md` "Hand-off between projects"; `inbox.md`; the `inbox` skill; `test-wake`, `test-inbox`.

**Status:** STANDING.
