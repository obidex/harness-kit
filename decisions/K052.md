## K052 · 2026-11-20 · STANDING — one file per decision; the old register is closed

**Owner (20 Nov 2026, project chat).** "Decisions written one file per decision so parallel threads stop
conflicting."

**Context.** A register kept as one file gains each entry on its last lines, so two threads that each
record a decision always conflict there. With every ready card running at once (K051) that is every batch.

**Decision.**
1. A new decision is its own file, `decisions/<ID>.md`, beside the project's existing register; the ID
   stays the project's own series (K…, and each project's letter).
2. The existing register is closed, not split: it keeps every entry unchanged and gains none. Nothing is
   migrated, so no open work conflicts with the switch, and every citation of an old ID still resolves.
3. `tools/decisions.mjs check` holds it: files named `<ID>.md` whose first line names that ID, a number
   used once, the log's numbers all below the files' (an entry appended after the switch fails). The
   audit's C17 runs it and flags a decision file changed after it was written; `check-kit` runs it on the
   kit. `decisions.mjs next` prints the next free ID.
4. The path is the number. Two threads that take one number add the same file, which git shows on the later
   pull request before a merge; the later thread renames its file and never merges two texts.
5. C17's loaded line is unchanged ("append-only: supersede, never edit"); the shape is in its record and
   `.harness/decisions.md`, since core is at its cap.

**Rejected.** `<ID>-<title>.md`: two threads with one number would merge cleanly and the duplicate would
show only on the default branch. An ID taken from the pull request's number: never clashes, but it breaks
each project's series and cannot be known before the pull request exists. Splitting the old register into
files: a large rewrite that conflicts with every thread appending to it that day, for no gain.

Homes: `.harness/decisions.md`; `tools/decisions.mjs`; `audit.mjs` C17 and its record; `check-kit` (11);
`tools/test-decisions.mjs`; this repository's `DECISIONS.md` (closed at K050) and `decisions/`.

**Status:** STANDING.
